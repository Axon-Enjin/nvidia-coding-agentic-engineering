# Coding & Agentic Engineering

Track repo for the Nebius x NVIDIA Global AI Hackathon. This folder is the whole project: rules, sponsor context, the research prompt, and the research report. It does not depend on any other local folder.

- **Hackathon:** Nebius x NVIDIA Global AI Hackathon
- **Deadline:** 30 Oct 2026, 10:00 AM PT
- **Track:** Build coding agents and developer tools that write, run, and test code in Token Factory Sandboxes

## Recommended build

**VibeSec** — an adversarial agent that forks a Nebius Sandbox and tries many exploits against an AI-generated app, then reports what landed. The report's weighted score is 9.47, ahead of SafeForge (7.30) and Underwrite-AI (7.12).

Global SOM in the report is about $37.5M ARR. The Philippine and SEA beachhead is about $7.56M ARR. Pivot to SafeForge if sandbox branching cannot run attacks in parallel.
